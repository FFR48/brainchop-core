# Baseline invocation matrix for the modular refactor.
#
# Each case runs into its own output directory, so files a case writes as a side
# effect (--mask, --export-classes class maps) land there with no bookkeeping:
# the whole directory is digested.
#
# Columns, pipe separated:
#   name     case identifier and output directory name
#   model    mindgrab | model16chan18cls  (selects which executable to invoke)
#   input    a tracked fixture name -> test/<name>.nii.gz
#            @extra/<name>          -> $BC_EXTRA_DIR/<name>.nii.gz, skipped
#                                      when BC_EXTRA_DIR is unset or absent
#   legacy   flags for the PRE-milestone-4 CLI, which is how test/baseline was
#            captured. No current build accepts --inverse-conform, so this
#            column now describes history: it is what the reference outputs were
#            produced with, not something a current binary can replay.
#   modular  flags for the per-model executables -- the dialect every current
#            build speaks -- or "-" if the case has no equivalent after the CLI
#            change (e.g. --crop on a label model)
#   retain   full   keep the output files (needed for tolerance comparisons)
#            digest keep only the checksums (--export-classes writes ~1 GB)
#   tol      maximum differing voxels; 0 means bit-exact
#
# @DIR@ expands to the case output directory.
#
# ---------------------------------------------------------------- test inputs
#
# CORE (tracked, always runnable -- these are the milestone gates):
#
#   t1_crop  256^3 at 1 mm, UINT8. Already on the grid conform targets, so
#            conformed and native output COINCIDE for it and --inverse-conform
#            is an identity. Good for the numerics, blind to the output space.
#   t1_2mm   96x128x128 at 2 mm, INT16. A real acquisition, so conform has to
#            upsample into 256^3 and the inverse reslice has to undo it, and
#            MindGrab has to restore INT16 on the way out. This is what makes
#            the milestone-4 output-space flip verifiable rather than merely
#            asserted, and it segments into all 18 classes.
#
# A synthesized oblique input was tried first and rejected: rotating and
# nearest-neighbour resampling t1_crop degraded it enough that model16 collapsed
# from 18 classes to 5, which is a weak regression signal. Real data at an
# honest resolution beats a synthetic grid.
#
# EXTENDED (opt-in, set BC_EXTRA_DIR; not tracked -- ~29 MB, absent from a fresh
# clone). Covers what the two tracked inputs cannot: UINT16, extreme
# through-plane anisotropy, thick-slice low-Z acquisitions that stress conform's
# out-of-field padding, oblique sforms, qform/sform disagreement, and modalities
# other than T1.
#
#   NOTE: model16 is a T1 parcellation model. Its output on T2w, FLAIR and fMRI
#   is anatomically meaningless. Those cases are REGRESSION signals -- they
#   detect change -- and must never be read as a correctness claim.
#
# ------------------------------------------------------------------- backends
#
# Every CPU case passes -cpu 0 EXPLICITLY. Without it bc_backend_select prefers
# CUDA, then Metal, then OpenCL, so a bare invocation on this machine runs the
# fp16 Metal path and no case would be bit-exact. -cpu 0 forces CPU and leaves
# the thread count automatic. Modular cases add --no-turbo: CPU turbo is the
# default and approximate; Metal cases add it for the fp16 path.
#
# Every model16 case pins its output space explicitly, because the two dialects
# disagree about the default: legacy defaults to conformed and needs
# --inverse-conform for native; modular defaults to native and needs
# --save-conform for conformed. Pinning both spellings keeps them comparable.
#
